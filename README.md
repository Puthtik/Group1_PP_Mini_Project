# Group1_PP_Mini_Project
Group 1 Java-Mini_Project Class Phnom Penh, Stock Management System

This is a console-based Product Management System that allows users to manage a list of products efficiently. Each product contains the following attributes:
  ID (Auto-generated): Unique identifier for each product.
  Name: Name of the product (e.g., Apple, Banana).
  Unit Price: Price per unit of the product.
  Quantity: Number of units available.
  Imported Date: Date when the product was imported.
The system provides a simple user interface (UI) to view products in a tabular format with pagination and total records summary. Users can navigate through pages and choose from various menu options to manage the product data.

Features:
  Display a list of all products with pagination.
  Add new products to the system.
  Read product details by ID.
  Update existing product information.
  Delete products from the system.
  Search products by name.
  Set the number of rows displayed per page.
  Save inserted or updated products to the database.
  View unsaved products before committing changes.
  Navigate through pages: First, Next, Previous, Last, or jump to a specific page.
  Backup and restore product data.
