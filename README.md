# Group1_PP_Mini_Project
Group 1 Java-Mini_Project Class Phnom Penh, Stock Management System

This is a console-based Product Management System that allows users to manage a list of products efficiently. Each product contains the following attributes:
  - ID (Auto-generated): Unique identifier for each product.
  - Name: Name of the product (e.g., Apple, Banana).
  - Unit Price: Price per unit of the product.
  - Quantity: Number of units available.
  - Imported Date: Date when the product was imported.
  - The system provides a simple user interface (UI) to view products in a tabular format with pagination and total records summary.
  -  Users can -navigate through pages and choose from various menu options to manage the product data.

## Features:
 Key	Action
  - N	Next page
  - P	Previous page
  - F	First page
  - L	Last page
  - G	Go to specific page
  - W	Write — stage new product (in memory)
  - R	Read product by ID
  - U	Update — stage changes (in memory)
  - D	Delete product immediately (with confirmation)
  - S	Search by name (partial, case-insensitive)
  - Se	Set number of rows per page
  - sa	Save → ui inserts · uu updates
  - Un	View unsaved / pending changes
  - Ba	Backup database to versioned SQL file
  - Re	Restore database from a backup file
  - E	Exit (prompts to save if changes pending)
